# Excel Sales Analysis

## Project Overview
This project focuses on analyzing sales data using Microsoft Excel 2013. It demonstrates data cleaning, data validation, PivotTables, PivotCharts, and an interactive dashboard to explore business performance and identify useful insights.

## Tools Used
- Microsoft Excel 2013
- Excel Tables
- Formulas and data validation
- PivotTables and PivotCharts
- Slicers
- Dashboard visualization

## Project Workflow
1. Examined the original sales dataset.
2. Identified and corrected missing, duplicate, inconsistent, and invalid records.
3. Documented corrections and validation checks in a Cleaning Log.
4. Prepared a cleaned dataset containing 500 records.
5. Analyzed sales, profit, products, customers, regions, categories, and payment methods using PivotTables.
6. Created an interactive dashboard with KPI cards, charts, and a Region slicer.

## Key Findings
- Total Sales: 317,362
- Total Profit: 82,905.07
- Overall Profit Margin: 26.12%
- Total Orders: 500
- South generated the highest regional sales and profit.
- Technology was the leading category by sales and profit.
- Laptops generated the highest product sales and profit.
- Digital Wallet was the most frequently used payment method.
- Profit per order decreased as discount levels increased.

## Dashboard
The dashboard presents:
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Monthly Sales and Profit Trend
- Sales and Profit by Region
- Sales and Profit by Category
- Top 10 Products by Sales
